# デザイントークン

`app/globals.css` の `:root` に定義されているトークンの参考資料です。値の正本は CSS で、この文書は「何がどこに使われるか」を示します。

更新規則:

- トークンを追加・変更・削除したら、同じコミットでこの表を更新する。
- 新しい色を置く前に既存トークンで表せないかを確認し、表せない場合だけ追加する。追加するときは `:root` の該当グループ（`Brand palette` と `Motion` のコメント付きブロック、またはその後ろのレイアウト値）に入れ、用途をコメントに書く。
- 文字色と背景の組み合わせは WCAG AA（本文 4.5:1、大きな見出し 3:1）を満たすものを選ぶ。`--orange` は表示用で、小さな文字や白文字の背景には `--orange-action`／`--orange-text` を使う。
- ダークテーマは存在しない。導入する場合はトークン層で切り替えられるよう、部品側に生の色値を書かない。

## 1. 配色

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--ink` | `#21385a` | 本文、見出し、ヘッダー背景の基調（ネイビー） |
| `--ink-deep` | `#16273d` | 濃いネイビー。ヒーロー背景、強調部分 |
| `--paper` | `#f7f5ee` | ページ背景（生成り） |
| `--paper-deep` | `#efede4` | 一段沈めた背景。フィルタ列、テーブルの帯 |
| `--white` | `#fffefa` | カードやパネルの面 |
| `--orange` | `#f59120` | ブランドマークのオレンジ。大きな表示要素と装飾にのみ使う |
| `--orange-action` | `#b45a00` | 白文字を載せるボタン背景。コントラスト確保用の暗いオレンジ |
| `--orange-text` | `#9b4b00` | 生成り背景上のオレンジ文字 |
| `--orange-soft` | `#fdefda` | オレンジの薄い面。バッジや選択状態の背景 |
| `--sage` | `#8fa3bd` | 補助的な青灰。区切り、控えめなアイコン |
| `--line` | `#ddd9d4` | 罫線、枠線 |
| `--muted` | `#6b7686` | 補足文、ラベル |

ブランドの由来はハニカムのロゴマークで、ヒーローの蜂の巣アニメーションもこの配色（`--ink-deep` 上の暖色）で構成されています。

## 2. 影

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--shadow` | `0 20px 50px rgba(22,39,61,0.09)` | 浮いている面（カード hover、ボトムシート、パネル）。影は 1 種類だけ |

角丸はトークン化されておらず、部品ごとに直接指定されています。統一が必要になったら `--radius-*` として追加し、この表に載せます。

## 3. モーション

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--ease-settle` | `cubic-bezier(.22, 1, .36, 1)` | 到着する動き（登場、シートの開き）。速く始まり、長く静かに着地する |
| `--ease-standard` | `cubic-bezier(.4, 0, .2, 1)` | その場で状態が変わる動き（色、ハイライトの移動） |
| `--dur-quick` | `.15s` | 押下、hover、色の変化 |
| `--dur-base` | `.28s` | ページの fade、ハイライトの移動 |
| `--dur-enter` | `.42s` | 一覧項目の登場 |
| `--stagger-step` | `34ms` | 登場カスケードの隣同士の間隔。`lib/motion.ts` と共有 |

## 4. レイアウト

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--discovery-bar-h` | `65px`（640px 以下では `57px`） | sticky なディスカバリーバーの高さ。バー自身と、その下に留まるデスクトップのフィルタ列が同じ値を読む |

ブレークポイント（920px、720px、640px）はトークンではなくメディアクエリに直接書かれています。位置は [`STYLING_STRATEGY.md`](./STYLING_STRATEGY.md) §2 を参照してください。
